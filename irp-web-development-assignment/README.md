# IRP Web Development Assignment

This repository contains the required deliverables for the IRP LMS responsive UI and JavaScript banking simulation assignment.

## Project structure

```text
irp-web-development-assignment/
├── part-a-responsive-ui/
│   ├── index.html
│   └── style.css
├── part-b-javascript/
│   └── bank.js
└── README.md
```

## Part A: Responsive UI

Open `part-a-responsive-ui/index.html` in a browser to review the IRP LMS landing page.

Recommended testing steps:

1. Open the page in Google Chrome.
2. Check the sticky navigation bar remains anchored at the top while scrolling.
3. Resize the browser to desktop and mobile widths to confirm the responsive layout.
4. Confirm the hero section stacks properly on smaller screens and the step cards collapse into one column on mobile devices.

## Part B: JavaScript Bank Simulator

This file includes:

- Strict validation for bank deposit amounts in `parseAmount()`
- Type coercion and error handling examples
- Correct use of `const`, `let`, and hoisting examples
- A comparison of `var` and `let` behavior in loop scope
